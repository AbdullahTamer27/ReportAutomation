📷 Image naming guide

          

            Put the photos in an IMGS folder inside your working directory
            (or directly in the folder itself). Use the exact base name below — any of
            .png .jpg .jpeg .tif
            .tiff is accepted.

            Damage photos — 3 per damage point, named

            e.g. DMG1_1, DMG1_2, DMG1_3, DMG2_1…
